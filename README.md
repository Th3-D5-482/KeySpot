# 🎹 KeySpot

> Hear it. Know the key. Play along.

KeySpot instantly detects the musical key of any song.

Perfect for musicians who want to quickly find a song's key and start playing without wasting time.

## ✨ Features

- 🎵 Key Detection
- 🔁 Transpose between musical keys
- 🌙 Dark Mode
- ⚡ Fast & Simple
- 🚫 No Login
- 🚫 No Account
- 🚫 No Subscription

## 📱 How It Works

1. Tap **Listen**
2. Let KeySpot analyze the song
3. See the detected key
4. Enter the original key and the target key to see the transposition
5. Compare the relative chords in both keys, then play along

## 🔁 Transpose

Enter an original key and the key you want to play in. KeySpot shows the semitone change in both directions, so you can choose the shift that suits your instrument.

For example, moving from **A** to **C** can be shown as **+3 semitones** (up) or **−9 semitones** (down). Both shifts reach the same target key, one octave apart.

KeySpot can also show the diatonic chords for the original and target keys side by side:

| Chord degree | A major (original) | C major (target) |
| --- | --- | --- |
| I | A | C |
| ii | Bm | Dm |
| iii | C♯m | Em |
| IV | D | F |
| V | E | G |
| vi | F♯m | Am |

Use the semitone change to transpose a keyboard, or use the target key to find a guitar capo position that lets you play familiar chord shapes in the song's key.
